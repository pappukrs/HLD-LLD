Proxy: a stand-in that controls access

The ledger takes 800 ms per statement. A caching proxy with the same interface answers repeats in about 1 ms, merges concurrent misses, and expires entries. A protection proxy in front rejects forbidden reads before the cache is touched. The controller never changes.

The caching proxy

class CachingStatementProxy implements StatementService {
  private cache = new Map<string, Entry>();
  private inFlight = new Map<string, Promise<Statement>>();

  async getStatement(id: string) {
    const hit = this.cache.get(id);
    if (hit && hit.expiresAt > this.now()) return hit.value; // HIT
    const p = this.inFlight.get(id);
    if (p) return p;                       // coalesce misses
    const call = this.real.getStatement(id)
      .then((v) => { this.cache.set(id, { value: v,
          expiresAt: this.now() + this.ttlMs }); return v; })
      .finally(() => this.inFlight.delete(id));
    this.inFlight.set(id, call);
    return call;
  }
}
// wiring: new AuthProxy(new CachingProxy(new Ledger(), 60_000), user)

Try it: drive the caching proxy

    Say this in the interview

    "The statement service is slow, so I put a caching proxy in front of it. It implements the same interface, so the controller doesn't change. The cache has a TTL and a size cap, and it coalesces concurrent misses so a cold key hits the ledger once. Auth is a separate protection proxy placed outside the cache, so it runs on every call."

    Check yourself

    Proxy vs Decorator: what is the real difference?
    Intent. Same structure. A decorator adds behaviour and is often stacked by the client. A proxy controls access to one real object: it can skip the real call (cache, auth) or delay creating it (lazy).
    Why must auth wrap the cache, not the other way round?
    If the cache is outermost, a forbidden user can read a value that another user's request already cached. Access checks must run before any data is returned.
    100 requests miss the same cold key at once. How many ledger calls?
    Without coalescing, 100 (a cache stampede). With an in-flight promise map, 1: the other 99 await the same promise.
    Which kind of proxy is a gRPC client stub?
    A remote proxy: a local object with the service's interface that turns each call into a network request. Give it a deadline and handle UNAVAILABLE.
