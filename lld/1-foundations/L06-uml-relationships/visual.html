UML class diagrams and relationships

Six lines connect the boxes in a class diagram. The arrowhead tells the reader how strong the link is and who controls whose lifetime. Draw them right and the interviewer reads your design in seconds. At the end we use all six on a parking lot.

Association Aggregation Composition Dependency Inheritance Realization

Say this in the interview

"A ParkingLot is composed of Floors: if the lot is deleted, its floors go too, so I draw a filled diamond. Each Floor owns its Spots the same way. A Spot holds a Vehicle that comes and goes, so that is a hollow diamond. A Ticket knows its Spot: plain association. Car and Bike extend Vehicle, and every pricing rule realizes a PricingStrategy interface."

The same six links in TypeScript

// association: a long-lived reference (field)class Order { constructor(public customer: Customer) {} }// aggregation: parts are made outside and passed inclass Team { players: Player[] = []; add(p: Player) { this.players.push(p); } }// composition: the whole creates and owns its partsclass House { private rooms = [new Room('hall'), new Room('kitchen')]; }// dependency: used only inside a method (param or local)class OrderService { notify(mail: EmailClient) { mail.send('...'); } }class Dog extends Animal {}                  // inheritanceclass CardPayment implements Payable {       // realization  pay(amount: number) { /* ... */ }}

How to tell them apart

LinkDrawn asMeansLifetimeIn code
DependencyDashed line, open arrow"uses for a moment"No link after the callMethod parameter, local variable, static call
AssociationSolid line, open arrow (or none)"knows a"IndependentA field that holds a reference
AggregationHollow diamond at the whole"has a", parts are sharedParts outlive the wholeParts passed in from outside
CompositionFilled diamond at the whole"owns a", parts are privateParts die with the wholeParts created inside, never handed out

Check yourself

Which end gets the diamond?
The whole (the container). House ◆—— Room: the diamond touches House.
Library and Book: aggregation or composition?
Usually aggregation: a book can move to another library and still exist. Book and Page is composition: pages have no life without their book.
What does 0..1 mean next to a class?
From the other side, you link to zero or one of this class. Write the number next to the class it counts. "Team 0..1 —— * Player" reads: a player is in at most one team, and a team has many players.
Is dependency weaker than association?
Yes. Dependency is temporary use inside a method. Association is a stored reference, so the two classes stay coupled for as long as the object lives.
