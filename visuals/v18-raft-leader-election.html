Raft Leader Election

Raft keeps one log the same on every server. One leader takes all writes. An entry is committed when a majority stores it. When the leader dies, a node with an up-to-date log wins a new term.

Follower Candidate / vote request Leader / AppendEntries Vote yes / ack / committed Vote no / lost

Say this in the interview

"I'd use a Raft group of 3 or 5 nodes, for example etcd or ZooKeeper, to elect one leader. Followers start an election when heartbeats stop for a random 150–300 ms. A node wins with votes from a majority, and nodes only vote for a candidate whose log is at least as new as theirs. Writes go through the leader and commit once a majority has them, so a committed write survives any minority failure."

Why a majority matters

  • Any two majorities share at least one node. So a new leader always meets a node that has every committed entry.
  • 5 nodes tolerate 2 failures; 3 nodes tolerate 1. 4 nodes still tolerate only 1, so use odd sizes.
  • A minority side of a network split cannot elect a leader or commit writes. This is how Raft avoids split brain.
  • Terms act as a logical clock: any message with a higher term makes an old leader step down.

Check yourself

Why are election timeouts random?
If all followers timed out together, they would all become candidates, split the votes, and nobody would win. A random timeout means one node usually starts first and wins before the others wake up.
Can a node with a stale log become leader?
No. Voters refuse a candidate whose log is older than theirs. Since a committed entry is on a majority, every possible winner's majority includes at least one node that would refuse a stale candidate.
The old leader comes back after a network split. What happens?
It still thinks it is leader of the old term. Its first message or reply shows a higher term, so it steps down. Its uncommitted entries that conflict with the new leader's log are overwritten.
Raft vs a Redis lock for leader election?
A Redis lock with a TTL can give two leaders during a GC pause or clock jump. Raft (or a ZooKeeper/etcd lease plus a fencing token) gives a safe single leader. Use fencing tokens whenever the leader writes to an outside system.
